<h1>Simple CPU</h1>
This Verilog code implements a Simple CPU with a 5-stage instruction cycle (fetch, decode, operand fetch, execute). It supports basic operations like LOAD, ADD, STORE, and JUMP using a 16-bit architecture with 64-word memory. The CPU processes instructions sequentially, updating registers (PC, IR, MBR, AC, MAR) and memory based on opcodes.
